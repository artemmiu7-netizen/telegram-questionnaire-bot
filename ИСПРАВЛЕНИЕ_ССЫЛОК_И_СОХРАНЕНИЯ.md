# Исправление ссылок и сохранения анкет ММУ

Эти изменения находятся в отдельной ветке `fix/link-lead-sync`. Основная ветка `main` не изменена.

## Что исправлено

- Бот передаёт `manager_code` вместе с кодом УЗ при сохранении контакта.
- Функция отправки анкеты возвращает результат Google Apps Script.
- Бот больше не подтверждает отправку анкеты, пока Google Sheets не вернул `ok: true`.
- Apps Script записывает коды специальности, УЗ и менеджера в столбцы W, X и Y.
- Apps Script не перезаписывает существующую строку заголовков.
- Секрет интеграции читается из Script Properties, а не хранится в исходном коде.
- Запрос без Telegram ID отклоняется, чтобы не создавать пустые строки.

## Что пока не сделано

Этот вариант сохраняет коды УЗ и менеджера в главном листе `Заявки`. Автоматическое распределение в отдельные таблицы УЗ и менеджеров не включено в эту версию: для безопасной реализации нужно сверить актуальный развёрнутый Apps Script и точные настройки листов `Реестр УЗ`, `Менеджеры` и `Распределение УЗ`.

## Настройка секрета Apps Script

1. В Apps Script открой **Настройки проекта**.
2. Найди раздел **Свойства скрипта**.
3. Добавь свойство с именем `GOOGLE_SHEET_SECRET`.
4. В значение внеси новый секрет, который совпадает со значением переменной `GOOGLE_SHEET_SECRET` в Deployka.
5. Не вставляй секрет в код, GitHub, сообщения или скриншоты.

Поскольку прежний секрет находился в публичном репозитории, его необходимо заменить и в Deployka, и в Apps Script. Простое удаление значения из последнего коммита не удаляет его из истории Git.

## Развёртывание

- В Deployka используй ветку `fix/link-lead-sync` для проверки изменений либо сначала проверь и объедини Pull Request.
- Для Apps Script скопируй обновлённый файл `google_apps_script_mmu.gs` в существующий проект, сохрани и выпусти новую версию веб-приложения.
- Проверь, что `GOOGLE_SCRIPT_URL` в Deployka указывает на URL веб-приложения с окончанием `/exec`.
- Не запускай `setupAll()` ради проверки: эта функция очищает и заново формирует листы `ДОД` и `Статистика`. Существующие данные в этих листах могут быть затронуты.

## Проверка

1. Открой бота по обычной ссылке и отправь тестовую анкету.
2. Повтори через ссылку вида `?start=uz_КОД`.
3. Повтори через ссылку вида `?start=uz_КОД_mgr_КОДМЕНЕДЖЕРА`.
4. В листе `Заявки` проверь Telegram ID, источник, код УЗ и код менеджера.
5. Убедись, что при ошибке Google Sheets бот не показывает подтверждение об успешной отправке.
